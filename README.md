# E-commerce Web Template for Shop & Retail

A fully functional, responsive, and modern E-Commerce web application built using the **MVC (Model-View-Controller)** architectural pattern. This template provides a complete online retail experience, including user authentication, category filtering, real-time product search, discount displays, shopping cart management, and service request options.

---

## 🔑 Key Features

### 👤 User Authentication & Account Management
* **User Registration & Login:** Secure account creation, login, and session handling.
* **Header Navigation:** Quick access to user profile, shopping cart, and account settings.

### 🛒 Product & Shopping Experience
* **Brand & Category Filtering:** Easily filter and browse products by top brands (e.g., Apple, Samsung, Xiaomi, OPPO, Vivo, Realme, Infinix).
* **Real-time Product Search:** Integrated search bar allowing users to search products, services, or model names.
* **Dynamic Product Showcase:** Promotional banners and dynamic product cards tagged with labels like `New`, `Best Value`, and `Hot`.
* **Pricing & Discount Display:** Clear visual separation of original prices, discounted rates, and calculated savings (% OFF).
* **Detailed Product View:** Dedicated detail page for in-depth specs and descriptions.
* **Cart & Wishlist Support:** Interactive shopping cart counter and product wishlist (favorites) toggle.

### 🛠️ Integrated Support & Services
* **Repairs & Service Section:** Dedicated flow for customers to request device repair support.
* **Store Finder:** Quick navigation link to locate physical store locations.

---

## 🏗️ Tech Stack & Architecture

* **Architecture:** MVC (Model-View-Controller)
* **Frontend:** HTML5, CSS3, JavaScript, Responsive UI design
* **Backend:** PHP (MVC pattern)
* **Database:** MySQL
